# Baseline de rotas

Levantamento anterior à integração do motor de regras. A ficha existente é uma área preservada.

| Público | Jogador | Mestre | API crítica |
|---|---|---|---|
| `/login`, recuperação, termos e privacidade | `/app`, ficha, inventário, habilidades, mensagens, pistas, caderno e sala ao vivo | `/master`, campanha, central da sessão, membros, personagens, encontros, mensagens, pistas, cadernos, itens, mapas, atores, roteiros, auditoria e configurações | dados, recursos, habilidades, iniciativa, sessão, mapa, roteiro, mensagens, entregas e administração |

Rotas adicionadas pelo motor: `/app/help`, `/master/help`, APIs de regras, ajuda, segurança e testes estruturados.
